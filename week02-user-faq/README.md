## How can I change the resolution in Windows 11?

User goal:
To change the resolution.

Tool path tested:
Settings → System → Display

Steps:
1. Press Windows + I to open Settings.
2. Select the System tab.
3. In the Systems options, select Display
4. In Display options, look for Display resolution
5. On the dropdown menu in Display resolution, select your desired resolution

Evidence:

FAQ_1.2_System_Display_Sceenshot

When to escalate:
If there are no options in the menu or they don't match your monitor, you may have malfunctioning display drivers. Collect driver information and escalate to a senior technician.


## How can I see if a Driver is Malfunctioning or a Device is Disabled?

User goal:
See if a Driver is Malfunctioning or Disabled in Windows 11?

Tool path tested:
Start → Device Manager → Properties

Steps:
1. Right-Click the Start Button
2. Select the Device Manager tab.
3. In Device Manager you can see all the devices connected to a computer. Check to see if there are any yellow or red exclamation mark in a triangle. Yellow means a malfunctioning driver, and red means a device is disabled.
4. You can see the status of the selected device by Right-Clicking it, and selecting properties.
5. On the first tab that you start out in, General, look at the Device Status, that will tell you if the Device has any problems.
 
Evidence:

FAQ_2.3_Properties_Screenshot

When to escalate:
If you do have a driver malfunction, device disabled, or still having problems after checking and it looking clear, escalate to a senior technician.

## How can I change to another Language in Windows 11?

User goal:
Changing their Windows 11 to an language of their choosing.

Tool path tested:
Settings → Time & language → Language & region

Steps:
1. Press Windows + I to open settings
2. Select the Time & Language tab.
3. In Time & Language options, select Language & region
4. Look at the top of the options for Windows display language and use the dropdown menu to select the language you would like to use.
5. If you language is not there, look for the Blue Add a language button and select you language is the list that shows up.

## How can I change the size of my Mouse Pointer in Windows 11?

User goal:
Changing their Windows 11 Mouse Pointer to a size of their choosing

Tool path tested:
Settings → Accessibility → Mouse Pointer and touch

Steps:
1. Press Windows + I to open settings
2. Select the Accessibility tab.
3. In Accessibility options, select Mouse Pointer and touch
4. Look for a slider called Size, and move it to how big you want your Mouse Pointer to be.

## How do I find and stop startup programs in Windows 11?

User goal:
To be able to see and stop an application from opening automatically when Windows 11 starts.

Tool path tested:
Task Manager → Startup apps

Steps:
1. Press Ctrl + Shift + Esc to open Task Manager.
2. Select the Startup apps tab. (It has a gauge icon)
3. Find the application you want to not open on startup in the list.p
4. You can see if it is enabled or disabled by looking at the status bar to the right of the publisher.
4. If you want to disable the app, right-click the application and select the Disable option.
5. Restart Windows and make sure that the application no longer opens.

Evidence:
FAQ_5_Task_Manager_Startup_Screenshot

When to escalate:
If a startup application is not visible in Task Manager but the app still launches, escalate to a senior technician.
